# Archived: Google Cloud GPU scripts

Retired 10 Oct 2026. Ak's rule: no Google Cloud unless there is no other way.

These ran DramaBox (a voice model needing ~24 GB of graphics memory) on a rented
Google Cloud L4 machine in project `tier-1-ak`. That machine and its disk were
deleted on 8 Sep 2026, the project's storage bucket is gone, and `tier-1-ak`
itself no longer works. Kept only as a record of what was tried; nothing in the
app calls them.
